# Uni Mining HUD

**A free, compact mining-signature overlay for Star Citizen (Windows).**  
**Ein kostenloses, kompaktes Overlay für Mining-Signaturen in Star Citizen (Windows).**

[English](#english) · [Deutsch](#deutsch)

## English

Uni Mining HUD displays mining signatures in a customizable, always-on-top SCAN overlay while you play Star Citizen. This is an independent community utility for **ship mining**.

### Features

- German and English interface
- Ore-signature matrix with 1–6 rock columns and configurable ore rows
- Location selections and custom saved profiles
- Optional editable NOTE below the SCAN display
- Move mode and a transparent HUD
- Configurable keyboard shortcuts; defaults are listed below
- No account required; free to use

### Download & start

1. Open **Releases** on this GitHub repository and select **v1.7.1**.
2. Download **`UniMiningHUD.exe`** from the release assets, not GitHub's automatically generated *Source code* ZIP.
3. Start the program on Windows and choose your settings. For Star Citizen, borderless windowed mode is recommended.

**Default shortcuts**

| Shortcut | Action |
| --- | --- |
| Alt + Shift + F7 | HUD / settings |
| Alt + Shift + F8 | Show / hide (Vanish) |
| Alt + Shift + F9 | Move / lock |
| Alt + Shift + F10 | Edit NOTE |

Shortcuts can be changed in settings. Ore and location information are reference data and may change with game updates.

**Windows security notice:** This EXE is currently unsigned. Microsoft Smart App Control or SmartScreen may block it on some PCs. Do not disable Windows security protections just to run the tool. The SHA-256 checksum is provided with each release to verify file integrity; it is not a security certification.

## Deutsch

Uni Mining HUD zeigt dir Bergbau-Signaturen während Star Citizen in einem anpassbaren, auf Wunsch transparenten **SCAN-Overlay**. Das kostenlose Community-Tool ist für **Schiff-Mining** ausgelegt.

### Funktionen

- Oberfläche auf Deutsch und Englisch
- Erz-Matrix mit 1–6 Steinspalten und variabler Anzahl an Erzzeilen
- Fundort-Vorauswahl und eigene gespeicherte Profile
- Optionaler NOTE-Bereich unter der Signaturanzeige
- Verschiebemodus und transparentes HUD
- Frei einstellbare Tastenkombinationen
- Kostenlos und ohne Benutzerkonto

### Download & Start

1. Öffne im GitHub-Projekt die **Releases** und wähle **v1.7.1**.
2. Lade dort unter den Release-Dateien **`UniMiningHUD.exe`** herunter. Die automatisch von GitHub erzeugten *Source code*-Archive sind nicht das Programm.
3. Starte die EXE unter Windows. Für Star Citizen empfiehlt sich der randlose Fenstermodus.

**Standard-Tastenkombinationen**

| Tasten | Funktion |
| --- | --- |
| Alt + Shift + F7 | HUD / Einstellungen |
| Alt + Shift + F8 | HUD ein-/ausblenden |
| Alt + Shift + F9 | Verschieben / verankern |
| Alt + Shift + F10 | NOTE bearbeiten |

Die Tastenkombinationen lassen sich ändern. Signatur- und Fundortdaten sind Nachschlagewerte und können sich mit Spielupdates ändern.

**Windows-Sicherheit:** Diese EXE ist derzeit nicht digital signiert. Smart App Control oder SmartScreen können sie auf manchen PCs blockieren. Bitte Windows-Sicherheitsfunktionen nicht allein wegen dieses Programms deaktivieren. Die SHA-256-Prüfsumme hilft, die Datei auf Unverändertheit zu prüfen; sie ist kein Sicherheitszertifikat.
